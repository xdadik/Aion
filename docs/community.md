# Community

Welcome to the Aion Hand community! 👋

## Where to find us

| Platform | Link | Purpose |
|---|---|---|
| GitHub Issues | [/issues](https://github.com/xdadik/Aion/issues) | Bug reports, feature requests |
| GitHub Discussions | [/discussions](https://github.com/xdadik/Aion/discussions) | Questions, design discussions, show & tell |
| Pull Requests | [/pulls](https://github.com/xdadik/Aion/pulls) | Code contributions |
| Wiki | [/wiki](https://github.com/xdadik/Aion/wiki) | Community-maintained guides |
| Website | (planned) | Marketing site, blog |

Real-time chat (Discord/Matrix) is planned for v0.5.0.

## Getting help

1. **Read the docs first** — [README](../README.md), [COOKBOOK](./examples/COOKBOOK.md), [FAQ](./FAQ.md)
2. **Search existing issues** — your question may already be answered
3. **Open a discussion** — for "how do I..." questions
4. **Open an issue** — for confirmed bugs with repro steps

## Community contributions

Beyond code, you can contribute by:

- **Writing skills** — share useful SKILL.md files (submit via PR to `skills/library/`)
- **Writing personas** — share SOUL.md templates (submit via PR to `aion_core/persona/templates/`)
- **Writing blog posts** — about how you use Aion (we'll link to them)
- **Giving talks** — at meetups, conferences
- **Answering questions** — in GitHub Discussions
- **Translating docs** — to other languages
- **Creating tutorials** — video or written

## Community guidelines

- **Be kind** — everyone was a beginner once
- **Be patient** — maintainers are volunteers
- **Be specific** — "it doesn't work" is not actionable
- **Be respectful** — see [Code of Conduct](../CODE_OF_CONDUCT.md)
- **Be helpful** — if you see a question you can answer, answer it

## Recognition

We recognize contributors in several ways:

- Listed in the [Contributors page](https://github.com/xdadik/Aion/graphs/contributors)
- Mentioned in release notes for significant contributions
- "Contributor" role in GitHub Discussions for active participants
- "Maintainer" role (see [Governance](../GOVERNANCE.md)) for long-term contributors
